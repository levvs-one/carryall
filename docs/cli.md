# Carryall CLI

`carryall.exe` использует то же ядро, что и GUI. Он подходит для скриптов, CI и повторяемой подготовки комплектов.

## Сборка

```text
carryall build <результат> <источник> [источник...] [опции]
```

Если `--format` не задан, путь с расширением `.zip` означает ZIP, остальные пути — папку.

Пример:

```powershell
carryall build .\handover.zip .\drawings .\spec.pdf --format zip
```

### Ограничения

```text
--allow-ext .pdf,.dwg
--require drawings/final.dwg
--max-file-mib 200
--max-total-mib 1500
--max-output-mib 1700
```

`--allow-ext` и `--require` можно повторять. Размеры задаются в МиБ (1 МиБ = 1 048 576 байт).

## Проверка

```text
carryall verify <комплект> [--format zip|folder]
```

Для `.zip` формат определяется автоматически. Для каталога используется `folder`.

При успехе команда печатает строку:

```text
OK    <число файлов>    <байт материалов>    <путь>
```

## Коды завершения

- `0` — успех.
- `1` — ошибка ввода-вывода или среды.
- `2` — план сборки не прошёл правила/проверки.
- `3` — существующий комплект не прошёл верификацию.
- `64` — ошибка синтаксиса CLI.
- `130` — отмена через Ctrl+C.

## Важные свойства

CLI не обходит защитные проверки GUI. Сборка по-прежнему:

- запрещает перезапись существующего результата;
- не публикует результат до повторной верификации;
- отклоняет ссылки/reparse points;
- проверяет, что исходники не изменились после сканирования;
- оставляет только явно помеченный `.incomplete` объект при отмене или ошибке записи.
