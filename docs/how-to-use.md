# Как пользоваться Handinpack

Три задачи: подготовить передачу, повторить её по сохранённому набору и проверить полученный комплект. Для запуска из исходников используйте [README](../README.md#запуск-из-исходников). Здесь предполагается, что окно приложения уже открыто.

В версии 0.1 используйте источники, место результата и рецепты на обычных локальных дисках.

## Собрать комплект с нужными именами и ограничениями

1. Добавьте файлы или папки. Папка попадает в опись со своим именем: например, файл `Чертежи/этаж.pdf` сохранит этот относительный путь. Отдельно добавленный файл получает собственное имя без родительского каталога.
2. Найдите нужную строку через **«Поиск по файлам»**. В фильтре **«Требует решения»** видны позиции с ошибками; общие проблемы набора показаны в сводке справа.
3. Выберите строку, измените поле **«Путь копии в комплекте»** и нажмите **«Применить имя копии»**. Например, `Чертежи/этаж.pdf` можно заменить на `01-чертежи/этаж.pdf`. Исходник останется на месте. Не используйте абсолютные пути, `..` и имена устройств Windows.
4. Чтобы убрать материалы из передачи, выберите одну или несколько строк, укажите причину и нажмите **«Исключить из комплекта»**. Сами файлы не удаляются. В готовую опись попадут их относительные имена и причина исключения, но не содержимое.
5. При необходимости откройте **«Требования к комплекту»**:

   | Поле | Что вводить |
   | --- | --- |
   | Допустимые расширения | Например, `.pdf, .jpg, .txt`. Список относится к итоговым именам копий, а не к распознаванию содержимого файлов. |
   | Один файл, МиБ | Верхнюю границу размера каждого включённого файла. |
   | Все материалы, МиБ | Верхнюю границу суммы включённых файлов до сжатия. |
   | Готовый комплект, МиБ | Верхнюю границу фактической записи с обеими описями. Для ZIP учитывается сжатый архив целиком. |
   | Обязательные пути в комплекте | Точные относительные пути, по одному на строку. Это не шаблоны и не маски. |

   Пустые поля не добавляют пользовательского ограничения. Число МиБ может быть дробным с точкой или запятой; 1 МиБ = 1 048 576 байт. Встроенные [ограничения формата](format.md#ограничения) продолжают действовать.

6. Укажите имя нового комплекта, формат **ZIP** или **Папка** и существующую родительскую папку. В режиме ZIP расширение `.zip` добавится, если его нет. Не выбирайте папку результата внутри исходного каталога.
7. Нажмите **«Собрать и проверить»**. Передавайте результат только после сообщения **«Комплект проверен»**. Кнопка **«Показать результат»** откроет папку комплекта либо папку, содержащую ZIP.

Чтобы полностью убрать ошибочно добавленный корень из плана, выберите его в списке источников и нажмите **«Убрать из плана»**. Кнопка **«Источники»** в верхней полосе даёт доступ к той же операции, в том числе в узком окне.

## Повторить передачу по сохранённому набору

1. Подготовьте состав, имена, причины исключения и требования. Нажмите **«Сохранить набор»** и выберите новое имя файла `.handinpack.json`.
2. Храните этот файл у себя. Он содержит абсолютные локальные пути и не добавляется в комплект автоматически. Не включайте его в исходные материалы, если не хотите передать эти пути получателю.
3. В следующий раз нажмите **«Открыть набор»** и выберите рецепт. Handinpack заново прочитает источники, затем применит сохранённые имена и включение к найденным файлам.
4. Проверьте опись, особенно новые и исчезнувшие файлы. Новый файл в исходной папке может войти в новый план; рецепт не фиксирует неизменный снимок её содержимого. Недоступные источники нужно восстановить либо убрать из плана.
5. Выберите новое имя результата и соберите его. Старый комплект не перезаписывается.

Сохранение рецепта не сохраняет копии файлов. Перед закрытием приложения или открытием другого набора сохраните нужные настройки самостоятельно. У сохранения нет автоматической замены прежнего рецепта: для новой редакции выбирайте новое имя.

Пути источников и назначения внутри рецепта должны указывать на обычные локальные диски. UNC, специальные пути устройств, подключённые сетевые диски, junction и облачные заполнители не используются для автоматического восстановления набора. Если прежний источник был сетевым, сначала подготовьте локальную копию и создайте новый рецепт с ней.

## Проверить существующий комплект

1. Выберите в поле **«Формат»** тип результата: **ZIP** или **Папка**.
2. Нажмите **«Проверить комплект»** и выберите архив либо корневую папку, содержащую `handinpack.json` и `contents.txt`. Для этой операции не нужно добавлять исходники или задавать имя нового результата.
3. Дождитесь результата. **«Комплект проверен»** означает совпадение состава, длин и хешей с описью. При ошибке приложение перечислит обнаруженные несовпадения.

ZIP читается через потоки и не распаковывается на диск. Проверка не удаляет лишние файлы, не восстанавливает недостающие и не переписывает хеши. Обычный ZIP без Handinpack-описи не считается проверенным комплектом.

Совпадение с описью не устанавливает отправителя и не делает вложения безопасными для открытия. Подробности - в [границах проверки](format.md#границы-проверки).

## Клавиатура

| Действие | Клавиши |
| --- | --- |
| Перейти в поиск | Ctrl+F |
| Выбрать строки описи | Стрелки, Shift или Ctrl со стандартным выделением таблицы |
| Включить или исключить выбранные строки | Space, когда фокус в описи |
| Перейти к имени выбранной копии | F2 |
| Перейти между описью и названием комплекта | F6 |
| Отменить изменение имени или включения | Ctrl+Z вне текстового поля, до 32 последних правок |
| Перейти между доступными элементами | Tab / Shift+Tab |

В текстовом поле Ctrl+Z отменяет редактирование текста. После изменения пути копии нажмите **«Применить имя копии»**; переход фокуса сам по себе не применяет правку. Повторное сканирование источников или открытие рецепта начинает новую историю отмены. Для остановки сборки перейдите к кнопке **«Отменить»** и активируйте её; Escape сам по себе операцию не отменяет.

## Если что-то пошло не так

| Ситуация | Что сделать |
| --- | --- |
| «Собрать и проверить» недоступна | Прочитайте сводку и пояснение под папкой результата. Нужны хотя бы один включённый файл, допустимые требования и свободное итоговое имя. |
| Совпали имена копий | Назначьте разные относительные пути или исключите одну позицию. Различия только в регистре или эквивалентном написании Unicode не создают разные имена. |
| «Обязательный файл отсутствует» | Включите нужную позицию либо исправьте обязательный путь. Исключение файла не снимает требование. |
| «Папка прочитана не полностью» | Исправьте доступ или уменьшите набор и перечитайте источник. Не отправляйте комплект на основе неполного списка. |
| Исходник изменился или занят | Остановите программу, записывающую этот файл. Повторно добавьте источник, чтобы обновить сведения, затем соберите под новым именем. |
| Ссылка, junction или облачный заполнитель | Выберите обычную локальную копию файла вне ссылочного пути. Приложение не обходит такие ограничения автоматически. |
| Рецепт ссылается на сетевое или специальное место | Подготовьте локальные копии, добавьте их в новый план и сохраните новый рецепт. Не заменяйте сетевой путь ссылкой на него. |
| Превышен размер готового результата | Уменьшите состав или измените лимит. Размер результата включает служебные описи; он проверяется после записи. |
| Проверка выявила лишние или изменённые файлы | Сверьте состав с отправителем или получите комплект заново. Не меняйте опись только ради успешной проверки. |
| Операция отменена или запись завершилась ошибкой | Посмотрите указанный промежуточный путь. `.incomplete` не является готовым результатом; автоматического продолжения с этого места нет. После остановки можно удалить именно этот объект вручную, если он больше не нужен. |
| Закрытие во время операции не закрыло окно | Приложение запросило отмену. Дождитесь остановки и закройте окно повторно. |

Ошибки диска и доступа не превращаются в сообщение об успешной сборке. При этом тестов с реальным исчерпанием свободного места на томе в текущем наборе нет.
