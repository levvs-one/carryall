# Changelog

Все заметные изменения Carryall документируются здесь.

## 0.2.0 — 2026-09-30

### Added

- `carryall.exe` — отдельный CLI для сборки и проверки комплектов.
- CLI-ограничения по расширениям, обязательным путям и размерам.
- Автоматизированный release workflow с self-contained GUI и CLI архивами.
- `SHA256SUMS.txt` для релизных артефактов.
- `SECURITY.md`, `CONTRIBUTING.md`, документация CLI и Dependabot.

### Changed

- GUI-бинарник переименован из `Handinpack.exe` в `Carryall.exe`.
- Версия приложения поднята до 0.2.0.
- CI теперь дополнительно проверяет CLI и обе publish-конфигурации.
- README перестроен вокруг текущего имени Carryall и двух способов использования.

### Compatibility

- Формат пакета не изменён.
- `handinpack.json`, `contents.txt` и schema version 1 сохранены.
- Рецепты `.handinpack.json` продолжают работать.

## 0.1.0 — 2026-09-04

- Первая публичная Windows-сборка под техническим именем Handinpack.
- GUI для планирования комплектов, ZIP/папка, SHA-256 manifest и повторная проверка.
- Защита от перезаписи, небезопасных путей, ссылок и изменения исходников во время сборки.
